# Fonts

The three families the application sets, self-hosted so a first paint does
not wait on a third party (#136). Each is the latin subset Google Fonts
serves, unchanged, and the `unicode-range` beside each face in `index.html`
is the one it was served with; Inter has its greek subset too, for the Δ.

| File                                     | Family           | Weights           | Licence                     |
| ---------------------------------------- | ---------------- | ----------------- | --------------------------- |
| `inter-latin.woff2`, `inter-greek.woff2` | Inter            | 400–600, variable | `LICENSE-Inter.txt`         |
| `plex-mono-{400,500,600}-latin.woff2`    | IBM Plex Mono    | 400, 500, 600     | `LICENSE-IBM-Plex-Mono.txt` |
| `barlow-condensed-600-latin.woff2`       | Barlow Condensed | 600               | `LICENSE-Barlow.txt`        |

All three are under the SIL Open Font License 1.1, copied beside them as
the licence asks.
